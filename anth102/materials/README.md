# Original ANTH 102 course materials

Put the original class files here (lecture slides, worksheets, Top Hat exports, the study guide, readings) and they
appear on the class's Archive page. Use a subfolder per unit if you like (`exam1/`, `exam2/`): each subfolder becomes
a group on the page. A `.txt` file holds links, one URL per line.

After adding or renaming files, run:

    node tools/build-archive.js
